# NexoTech – Pre-Entrega Front-End JS (Talento Tech)

Sitio web de una tienda ficticia de accesorios de computación, desarrollado como **Pre-Entrega del Proyecto** del curso Front-End JS de Talento Tech.

## Propósito

Presentar los productos de la tienda, mostrar opiniones de clientes y ofrecer un formulario de contacto para consultas, aplicando HTML, CSS externo y diseño responsivo.

## Qué incluye

| Requisito | Dónde está |
|---|---|
| Estructura semántica (`header`, `nav`, `main`, `section`, `footer`) | `index.html` |
| Formulario de contacto con Formspree (nombre, correo, mensaje) | Sección **Contacto** |
| CSS externo con estilos en header, footer y navegación | `css/styles.css` |
| Google Fonts (Space Grotesk e Inter) | `<head>` de `index.html` |
| Propiedades `background` (degradados y colores) | Header, Hero y Reseñas |
| Cards responsivas con **Flexbox** | Sección **Productos** |
| Distribución con **Grid** | Sección **Reseñas** |
| **Media Queries** | Sección **Contacto** (y Reseñas / navegación) |
| Multimedia: imágenes e `iframe` de Google Maps | Hero, Productos y Contacto |
| Lista desordenada de navegación interna | `nav` del header |


## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts
- Formspree
- Git y GitHub Pages
